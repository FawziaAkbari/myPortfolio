# Fawzia Akbari — Portfolio Website

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. No build tools or package installation required.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.
3. For the best editing experience, open the folder in VS Code and use Live Server if you have it installed.

## Personalize before publishing
Search `index.html` for these placeholders and update them:
- `YOUR_EMAIL@example.com` — replace with your professional email in both the email link and copy-email button.
- `https://github.com/` — replace with your actual GitHub profile URL.
- `https://www.linkedin.com/` — replace with your actual LinkedIn profile URL.

Review the role dates, project descriptions, and skills before publishing. Keep only details you can confidently verify. The project cards describe learning and teaching work, not commercial deployments. Add real GitHub repositories, live demos, and screenshots only when available. Do not present a project as completed if it is still in progress.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `fawzia-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The published URL will be shown in the Pages settings.

## Project structure
- `index.html` — page content and sections
- `style.css` — responsive styling and visual design
- `script.js` — mobile menu, current year, and copy-email interaction
